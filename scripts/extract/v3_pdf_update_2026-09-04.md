## 發現並修正的抽取程式 bug（跟 v3 本身無關，但沒修這題庫換不了）

`run_segmentation.py` 原本假設「每一頁表格的第 0 列都是表頭（A卷/B卷/…字樣）」，
V1 版 PDF 剛好每頁都重印表頭所以這個假設沒被戳破。v3 版改成整份表格只在每個
考卷區段開頭出現一次表頭列（可能出現在某頁 table 的中段），舊寫法會把每頁
第一筆真題目誤判為表頭而漏收，考卷代號也會卡在「A」永遠不會往下更新到
B/C/D/E/新增。已改成逐列掃描（不管表頭出現在哪一列都認得出來），對 V1、v3
兩版都正確，並補了 3 個回歸測試（`test_run_segmentation.py`）鎖住這個情境。
副作用：這個修正讓 Task 5 的原始口訣萃取從「V1 版只找到 2 句」多找到 2 句
（下面「口訣」段落有說明），跟 v3 無關，V1 版本身也一直漏收。

另外口訣抽取規則（`extract_mnemonics.py`）也有一個小 bug 一併修掉：「口訣」
後面直接接換行、換行之後才是『引號』的情況（`口訣\n『總是』`）沒處理好，
會讓規則失敗、退到備援規則貪婪吃進下一段內容，抓出「總是』→『總額」這種
殘缺片段。已修正並補測試。
