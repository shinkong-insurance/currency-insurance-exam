## 發現並修正的抽取程式 bug（跟 v3 本身無關，但沒修這題庫換不了）

`run_segmentation.py` 原本假設「每一頁表格的第 0 列都是表頭（A卷/B卷/…字樣）」，
V1 版 PDF 剛好每頁都重印表頭所以這個假設沒被戳破。v3 版改成整份表格只在每個
考卷區段開頭出現一次表頭列（可能出現在某頁 table 的中段），舊寫法會把每頁
第一筆真題目誤判為表頭而漏收，考卷代號也會卡在「A」永遠不會往下更新到
B/C/D/E/新增。已改成逐列掃描（不管表頭出現在哪一列都認得出來），對 V1、v3
兩版都正確，並補了 3 個回歸測試（`test_run_segmentation.py`）鎖住這個情境。
副作用：這個修正讓 Task 5 的原始口訣萃取從「V1 版只找到 2 句」多找到 2 句
（下面「口訣」段落有說明），跟 v3 無關，V1 版本身也一直漏收。

另外口訣抽取規則（`extract_mnemonics.py`）也有一個小 bug 一併修掉：「口訣」
後面直接接換行、換行之後才是『引號』的情況（`口訣\n『總是』`）沒處理好，
會讓規則失敗、退到備援規則貪婪吃進下一段內容，抓出「總是』→『總額」這種
殘缺片段。已修正並補測試。

## v3 版真正的內容修正（不在上述 114 題範圍內，都是全新或原本沒被涵蓋的題目）

比對出 15 筆題目有實質內容差異（非空白雜訊），其中比較重要的：

1. **B-49 / C-49 / E-4 三題連動的答案修正**：這三題都在問「內部稽核單位」
   或「業務單位」辦理招攬/核保/理賠/精算/保全/法務/投資相關作業的查核頻率。
   V1 版三題答案互相矛盾（有的答每季、有的答每半年），v3 版統一修正為
   「業務單位自行辦理的**專案自行查核**→**每半年**；**內部稽核單位**辦理的
   **專案查核**→**每年**」，並把這個規則寫進解析裡講清楚。這三題都不在
   已分類的 116 題範圍內（沒對應到任何一個章節的法規名稱），所以目前
   `questions_with_chapter.json`（供種子腳本使用的清單）**不會收錄它們**——
   如果之後要讓這三題正式上架，需要額外處理（人工指定 chapter_id，或
   放寬 `classify_chapters.py` 的規則）。
2. **A-15 / B-15：投資型保單死亡給付對保單帳戶價值比率門檻表整套換掉**。
   V1 版是舊的 3 級距表（15-40歲 130%、41-70歲 115%、71歲以上 101%），v3
   版換成新的 7 級距表（16-30歲 190%、31-40歲 160%、41-50歲 140%、51-60歲
   120%、61-70歲 110%、71-90歲 102%、91歲以上 100%），選項數字跟著全部更新。

   這是法規本身門檔表述方式的更新，不是單純數字修正。
