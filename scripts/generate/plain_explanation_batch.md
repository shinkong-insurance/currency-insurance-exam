## 內容審查後的修正紀錄

- **id 82(Ch5)**:原白話解析多加了一句「不需另外檢附證明文件」,但題本內與此相關的題目(id 30、id 54,涉及「證明文件」「逕行辦理」等概念)都沒有支持這個說法的內容,屬於捏造細節。已改寫為只依 id 82 本身的題目/選項/答案/原始解析(門檻五千萬美元、可逕行辦理結匯)作說明,移除「不需檢附證明文件」這句無根據的敘述。
- **id 108(Ch7)**:原白話解析宣稱2%上限「比BBB+級公司債適用的業主權益10%上限更加嚴格」,但這個比較是誤引:id 31(BBB+級公司債)只規定信評門檻,並未提及任何百分比上限;而題本內確實出現的「業主權益10%」上限(id 48)對應的是「BBB級」而非「BBB+級」評等,兩者評等層級不同,不能混為一談。已改寫為只依 id 108 本身四個選項(2%國外投資總額 vs. 20%/10%業主權益 vs. 10%國外投資總額)做對比說明,不再引用其他題目的評等層級做比較。

修正後兩則均已重新確認:字數落在80–150字區間、未以「根據法規」「依規定」等贅詞開頭、內容不含題本以外的新法規主張。其餘112題未變動。
